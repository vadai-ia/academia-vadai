# Prompts · Finanzas

## 1 · Análisis de variación

**Completa**
```
Actúa como contralor de una pyme mexicana. Analiza estas dos columnas, presupuesto y real del mes, y explica las cinco variaciones más grandes. Contexto: el director no es financiero y quiere entender, no auditar; el mes tuvo [evento relevante]. Tono claro, sin jerga contable. Formato: tabla con concepto, diferencia en pesos, diferencia en porcentaje y una línea de explicación; después, dos líneas de conclusión. No propongas acciones todavía, solo explica; no inventes causas: si no se puede saber con estos datos, dilo.
```
**Corta**
```
Explica las cinco variaciones más grandes entre presupuesto y real, para el director.
```

## 2 · Conciliación bancaria

**Completa**
```
Actúa como auxiliar contable senior. Concilia este estado de cuenta con este auxiliar y dime qué no cuadra. Contexto: la empresa es [giro], los movimientos recurrentes son [lista], y las diferencias de menos de [monto] son normales por comisiones. Tono técnico pero claro. Formato: tabla de partidas no conciliadas con fecha, monto, en cuál archivo aparece y en cuál no, y tu hipótesis; al final, el total sin conciliar. No marques como conciliado nada con diferencia mayor a [monto]; no propongas asientos contables.
```
**Corta**
```
Concilia este estado de cuenta con este auxiliar y dime qué no cuadra.
```

## 3 · Explicar el flujo al director

**Completa**
```
Actúa como director de finanzas de una empresa mediana. Explica esta proyección de flujo de efectivo a un director general que no es financiero. Contexto: el punto delicado es [semana o mes], por [razón], y la decisión que hay que tomar es [decisión]. Tono claro, sin alarmar ni minimizar. Formato: tres párrafos cortos, qué va a pasar, por qué, qué opciones hay; después una tabla con las opciones, su costo y su riesgo. No uses siglas sin explicarlas; no recomiendes una opción, presenta las tres.
```
**Corta**
```
Explica esta proyección de flujo al director, con el punto delicado y las opciones.
```
