# Prompts · Ventas

## 1 · Responder a un cliente

**Completa**
```
Actúa como director comercial con experiencia en venta consultiva en México. Redacta la respuesta a este correo del cliente. Contexto: [qué pasó antes: cotización, fecha, qué pide hoy]; lo que sí podemos ofrecer es [opción] y lo que no es [límite]. Tono cercano y seguro, sin rogar ni ceder. Formato: correo de máximo 120 palabras con saludo y despedida. No menciones a la competencia; no prometas nada que no esté en este mensaje; no ofrezcas descuento si no te lo autoricé.
```
**Corta**
```
Redacta la respuesta a este correo del cliente; sí podemos [opción], no podemos [límite].
```

## 2 · Resumen de cuentas para la semana

**Completa**
```
Actúa como gerente de ventas. Con estos correos y notas, arma el resumen de mis [N] cuentas activas para la semana. Contexto: mi meta del mes es [monto], cierro el [fecha], y las cuentas que más me preocupan son [lista]. Tono directo. Formato: tabla con cuenta, última interacción, siguiente paso, fecha y probabilidad (alta, media, baja); después, las tres llamadas que tengo que hacer hoy. No inventes interacciones que no estén en los correos; si una cuenta no tiene actividad, ponlo como "sin contacto desde [fecha]".
```
**Corta**
```
Arma el resumen de mis cuentas activas con estos correos y dime las tres llamadas de hoy.
```

## 3 · Manejar una objeción

**Completa**
```
Actúa como coach de ventas con experiencia en [giro]. El cliente dijo: "[objeción textual]". Contexto: vendemos [producto], su alternativa real es [competencia o no hacer nada], y el valor que más le importa es [valor]. Tono seguro, sin agresividad. Formato: tres formas distintas de responder, cada una en máximo 60 palabras, y cuándo usar cada una. No descalifiques al cliente ni a la competencia; no inventes garantías.
```
**Corta**
```
El cliente dijo "[objeción]". Dame tres formas de responder y cuándo usar cada una.
```
