# Prompts · Recursos Humanos

## 1 · Descripción de puesto

**Completa**
```
Actúa como gerente de recursos humanos de una empresa de [giro] con [N] personas. Redacta la descripción de puesto para [puesto]. Contexto: reporta a [área], el sueldo es según tabulador, y lo que más ha fallado en ese puesto antes es [problema]. Tono formal y cercano. Formato: objetivo del puesto en una línea, cinco funciones, tres requisitos, dos deseables. No pidas título universitario si el puesto no lo necesita; no incluyas sueldo; no uses adjetivos como "proactivo" o "dinámico".
```
**Corta**
```
Redacta la descripción de puesto de [puesto], que reporta a [área].
```

## 2 · Comunicado interno

**Completa**
```
Actúa como responsable de comunicación interna. Redacta el comunicado sobre [cambio: horario, política, beneficio]. Contexto: aplica desde [fecha], afecta a [quiénes], y la duda que más van a tener es [duda]. Tono claro y respetuoso, sin lenguaje legal. Formato: máximo 150 palabras, qué cambia, desde cuándo, a quién le toca, a quién preguntar. No uses "estimados colaboradores"; no amenaces con consecuencias; no des razones que no te di.
```
**Corta**
```
Redacta el comunicado de [cambio] que aplica desde [fecha].
```

## 3 · Guía de entrevista

**Completa**
```
Actúa como reclutador senior con experiencia en pymes mexicanas. Prepara la guía de entrevista para [puesto] con esta descripción de puesto adjunta. Contexto: la entrevista dura [minutos], la hace [quién], y lo que más nos importa detectar es [criterio]. Tono profesional. Formato: ocho preguntas, cada una con qué busca detectar y qué sería una buena y una mala respuesta; al final, tres señales de alerta. No incluyas preguntas sobre edad, estado civil, hijos ni religión; no hagas preguntas de acertijo.
```
**Corta**
```
Prepara la guía de entrevista de [puesto] con esta descripción, en [minutos].
```
