# Prompts · TI / Sistemas

## 1 · Política de uso de IA

**Completa**
```
Actúa como responsable de sistemas de una empresa mediana en México. Redacta la política interna de uso de herramientas de IA. Contexto: somos [N] usuarios, usamos [Google Workspace o Microsoft 365], ya hay gente usando IA por su cuenta y no hay regla escrita. Tono claro, para gente no técnica. Formato: una cuartilla con tres secciones, qué sí, qué no, a quién preguntar; y un semáforo de información (verde, amarillo, rojo) con tres ejemplos por color. No uses siglas sin explicarlas; no amenaces con sanciones; no prohíbas el uso: regúlalo.
```
**Corta**
```
Redacta la política de uso de IA para [N] usuarios con [suite], en una cuartilla y semáforo.
```

## 2 · Documentar un proceso de sistemas

**Completa**
```
Actúa como ingeniero de soporte senior. Documenta el proceso de [alta de usuario, respaldo, acceso a sistema] para que lo pueda seguir alguien de soporte nuevo. Contexto: los sistemas involucrados son [lista], y el error más común es [error]. Tono técnico pero legible. Formato: requisitos previos, pasos numerados con la pantalla o comando exacto, cómo verificar que quedó bien, y qué hacer si falla. No omitas pasos por "obvios"; no supongas permisos que no mencioné.
```
**Corta**
```
Documenta el proceso de [proceso] con estos sistemas, para soporte nuevo.
```

## 3 · Evaluar una herramienta

**Completa**
```
Actúa como arquitecto de TI de una pyme. Evalúa esta herramienta que quiere contratar [área] con esta información adjunta. Contexto: hoy usamos [sistemas], el presupuesto es [monto], y lo que más nos preocupa es [seguridad, integración, dependencia]. Tono objetivo. Formato: tabla con criterio, cómo cumple, riesgo (bajo, medio, alto) y qué preguntar al proveedor; al final, tres condiciones para decir que sí. No recomiendes contratar o no; da los elementos para decidir. No inventes capacidades que no estén en la información adjunta.
```
**Corta**
```
Evalúa esta herramienta para [área] con estos criterios y dime qué preguntar al proveedor.
```
