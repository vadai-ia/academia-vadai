## Ejercicio 1.7 · PACTO, tu primer prompt

Elige una tarea real de esta semana. Llena las cinco letras. Corre el prompt en Claude. Pega
abajo qué salió y qué le cambiarías.

| Letra | Pregunta guía | Lo mío |
|---|---|---|
| **P** · Perfil | ¿Quién quiero que sea la IA para esto? (oficio, nivel, contexto) | |
| **A** · Acción | ¿Qué quiero que haga? Un verbo. ¿Para quién? | |
| **C** · Contexto | ¿Qué no puede saber si no se lo digo? ¿Qué archivos, cifras, antecedentes? | |
| **T** · Tono y Formato | ¿Cómo debe sonar? ¿En qué forma sale? ¿Qué tan largo? | |
| **O** · Omisiones | ¿Qué NO debe hacer? ¿Qué no debe inventar, incluir o prometer? | |
