# Inter

Las fuentes de esta carpeta son Inter (Rasmus Andersson), bajadas de Google Fonts el
20-oct-2026 en sus pesos 500, 700 y 800. Licencia SIL Open Font License 1.1: se
pueden usar, incrustar y redistribuir libremente, también en productos comerciales.
https://openfontlicense.org

Las usa `lib/noticias/imagen.tsx` para dibujar las imágenes de las noticias y los
avisos de V-AI-P con `next/og` (que necesita el archivo de la fuente, no la web font).
